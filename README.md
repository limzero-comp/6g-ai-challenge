## 1. 赛题速览

### 1.1 要设计的三个模块

| 模块 | 部署 | 输入 → 输出 |
|---|---|---|
| `f_enc` 编码器 | 终端 | 下行信道 `H_i ∈ C^(2×16×144)` + SNR(dB) → 反馈 `U_i ∈ C^96` |
| `f_tx` 发射机 | 基站 | 2 用户比特(各 1152) + 反馈 `I_i` + SNR → `X ∈ C^(16×144)` + 5 ctrl 比特 |
| `f_rx` 接收机 | 终端 | `Y, H, b_ctrl, SNR` → LLR（长度 B ≤ 1152） |

### 1.2 硬约束

```text
N_ue=2, N_tx=16, N_rx=2, S_dl=144, S_ul=96, K=5, 每用户 B_max=1152 (144×8bit/RE)
snr_dl ~ U[-20,20] dB 两用户独立;  snr_ul = snr_dl - 10 dB
U、X 归一化单位能量; X complex64; b_ctrl ∈ {0,1}; LLR float32 有限值 (评测有 assert)
```

### 1.3 评分规则（A 榜）

- 单用户单样本：`μ = 100 × (B_c + 0.5(B_max−B)) / B_max` —— **没传的比特按 0.5（瞎猜期望）计分**
- 效率分 = 所有用户 μ 的均值；公平分 = μ 的第 10 百分位
- **A 榜 = 0.7×效率 + 0.3×公平**；总成绩 = 0.8×A榜名次 + 0.2×B榜名次（名次加权，越小越好）

评分规则的三条策略推论：
1. 准确率 < 50% 的传输不如不传；降速率不是换小星座（几乎无增益，见 DATA.md F12），而是**少发比特 + 跨 RE 编码**
2. 公平分（p10）被低 SNR 用户的信道容量卡住，≈52 已近物理墙；效率分（0.7 权重）才是主战场
3. SU 模式会让未服务用户恰好拿 50 分，压低公平分——**always-MU 优于带 SU 回退**

## 4. 数据结论速查（详见 DATA.md）

训练数据：100,000 样本 `[2, 2, 16, 144]` complex64（fp16 存储），无其他先验。

| # | 结论 |
|---|---|
| F1 | 瑞利型无视距，E\|h\|²=1.79，各天线/子载波统计均衡 |
| F2 | 时延域指数衰减 PDP，前 4 抽头含 95% 能量 → 反馈压缩空间巨大 |
| F3 | 频域平滑（间隔48相关 0.65）；子带内波动中位仅 0.105 → 逐子载波自适应收益有限 |
| F4 | **发射阵列为 8 阵位 × 双极化**（相关矩阵双块结构）→ 反馈/预编码按 (极化, 波束) 组织 |
| F5 | 双流有意义（s2/s1 中位 0.515），单流主导仅 9.5% |
| F6 | MU 天然低干扰（波束漏泄中位 0.151，>0.5 仅 4.4%）→ MU 是默认模式 |
| F7 | 两用户大尺度基本对称（增益比中位 1.02，5-95% 分位 [0.21, 4.96]） |
| F8 | 名义 SNR ≠ 实际 SNR：匹配波束增益 ~16dB，弱用户低速率传输仍可解 |
| F9 | 时延抽头锚定 tap0（69%），固定 DFT 基即可，无需学习抽头位置 |
| F10 | **f_enc 下界：192 实维 PCA 重建 NMSE 4.8%（-13.2dB）** |
| F11 | 方位角近各向同性（熵 0.979），用户可分性来自随机角度差，无固定角度结构可赌 |
| F12 | 方案评分上界：未编码路线天花板 ≈55.6，**跨 RE 编码路线 ≈67.8**（见下表） |

方案上界对比（完美 CSI + 蒙特卡洛 BER + 赛题评分，效率/公平/最终）：

| 方案 | 效率 | 公平 | 最终 |

## 5. 优化策略与路线图

### 优先级（依据 DATA.md F12 与评分规则）

1. **速率自适应的跨 RE 编码**（第一杠杆，效率 +17 分空间）
   发射端按信道条件发 B < 1152 比特并扩频到全部 RE，接收端解扩；5 个 ctrl 比特告知 B（32 档）。
2. **永远 MU**，不做 SU 回退；对 4% 配对不利样本做功率倾斜。
3. **f_enc 结构化压缩**：时延域（固定基）+ 波束域，向 192 实维 NMSE≈5% 对齐；注意上行噪声稳健性。
4. **训练侧**：SNR 采样与弱用户加权（公平分保底）；大 batch + H 常驻显存 + 早停加速迭代（官方 20 万步配方 4-6h，优化后 30-60min 等效）。
5. 明确跳过：调制阶数自适应（+0.25）、公平分专项投入（物理墙 ≈52）。

### 官方基线代码要点（基线的短板 = 改进点）

- Encoder 收了 snr 但完全没用 → SNR 条件化
- 固定 8 bit/RE，无速率自适应 → 路线 1
- ctrl 比特全 1 占位 → 用于传 B / 模式
- 预编码每子带（48 SC）一个 W（频域平滑下合理）；无 SU 逻辑（保持）
- 训练 BCE loss、Adam 1e-4、batch 100、20 万步、无验证/早停
