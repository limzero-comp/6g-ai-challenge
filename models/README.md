# 候选模型：全部未训练

三份 `modelDesign_v*.py` 均为独立、完整的官方接口实现，可以单独复制为提交文件 `modelDesign.py`，不需要本目录其他文件。请与同版本训练得到的三个权重文件配套，不能使用官方基线的旧权重。

| 版本 | 编码目标 | 参数量 | 用途 |
|---|---|---:|---|
| v1 | 每用户全1152bit，双流16QAM初始化及局部可学习调制 | 850,742 | 先建立可对照的端到端基线 |
| v2 | 自身SNR决定16–1152bit前缀，跨144RE编码 | 1,002,463 | 比较“少传、可靠传”策略 |
| v3 | 每用户全1152bit，跨144RE编码 | 1,002,463 | 主研究方向：按位失真优化 |

共同部分：频域/完整时延域CSI反馈、上行噪声收缩及SNR条件化重建、四空间流RZF与可学习修正、用户交换等变、仅使用官方输入的全局神经接收机。公共5bit编码两用户最小下行SNR的32档量化值，作为双方可用的全局条件；并不用于独立编码两用户的发送长度。

`Receiver.forward_full(...)` 始终给出1152个logit，供训练配合 `valid_lengths(snr, ctrl)` 做mask。`Receiver.forward(...)` 为正式提交接口，v2按实际前缀截断，并拒绝不同输出长度混在一个dense batch中。官方batch=1不受影响。

这些模型没有导频辅助的解析均衡器。接收机要从自己的H与Y推断由噪声反馈产生的有效信道；接口与梯度正确并不等于训练后一定能有效解决该问题。详细风险、验证顺序、命令见根目录 `MODEL_PLAN.md`。
