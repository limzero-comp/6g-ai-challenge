# 三 Agent 探索综合与我们的结合路线（2026-09-19 晚）

三个独立 Agent 在本仓库分支上各自探索到 ~65 分。本文档综合其结论，给出统一的事实基础与我们（mac-mini）的结合执行计划。

## 0. 成绩台账（各 Agent 的"最佳"，机制完全不同）

| Agent | 最佳 | 本地配对 | 机制一句话 |
|---|---|---|---:|
| GLM-1（glm_exp.md） | v13 四接收机集成 | 65.064（eff 71.706） | 副本物理接收机（v6 单机 64.99）+ 冻结空口多 RX LLR 集成 |
| Qwen（qwen_opt.md） | v5 | 65.04（E 71.556 / F 49.826，CI 64.83-65.23） | 块恒定结构化预编码 C·V + 8 导频 ridge-LS 解析均衡 + 5bit 角色协议 |

## 1. 三线一致的事实（可信度最高）

1. **端到端 JSCC 替代逐 RE 独立调制**（v1→v3 的 +1.4）：三方都以 v3 为起点。
2. **接收端"知道"等效信道是最大杠杆（+1.5~2.5）**，三种等价实现：
   - GLM-1：副本物理（重放 Encoder→Decoder × 真实自身信道，乘性复合）
   - Qwen：导频 + ridge-LS 估共享 beam-space V（恢复 ~99% oracle 信道知识，高 SNR μ 87-90→96-99）
   - Kimi：12 RE rank-4 Hadamard 导频穿同一预编码 + RX 逆推子带 H_eff（"中断量式提升"）
3. **CSIT/反馈质量不是瓶颈**：Qwen v8 修反馈 ρ 0.018→0.577 反而 -4.2；Kimi 完美 CSIT 重训 64.45≈64.54；我们消融无噪反馈仅 +1.2。
4. **前缀/降速率恒定有害**；但 **"重复发送 + LLR 合并"式的速率阶梯有效**（Kimi +0.5~1 主要 p10）——这正是我们 v5/v6 maj 编码的波形级实现。
5. **p10 地板 ≈50.1**（-18dB 容量 ~6bit），满传方案余量 ~0.1 分；我们的 maj3 微调拿到 p10 51.9 但效率 -2.2，净负——三方一致：p10 轴只剩 ~0.1-0.2 分空间。
6. **静态特征语义注入必死**（4 次教训，-1.1~-6.5）；**只有两类改动安全**：波形改动（收端语义不变）、零/小随机初始化的加性新通路。
7. **跨训练拼装接收机必死**（GLM-1 移植实验 59.8）；集成成员必须对冻结波形从头训练。
8. **链式热启动 >> 从零大模型**（Kimi：累计 380k 步的小模型 > 2.5×参数从零 80k）。
9. **方法论**：配对评测协议（同 split/seed/repeats/batch）；<0.1 的增益必须双协议复现；**诊断先行**（oracle 上界小就直接关闭方向）；EMA 0.999 双轨。
10. **工程**：官方 harness 参数上限 10M、复数矩阵运算需实数 2n×2n 分解（我们已有 `_complex_solve`）。

## 2. 各家证伪清单（不重复投入）

速率阶梯裸版（Qwen v6 63.89、GLM-1 v7 62.72）；SU 回退；导频叠加不回收导频税（Kimi 三参数化全证伪，rank-4 下回收 96 槽 = 污染 H_eff）；全局 Wiener 去噪；容量/时长扩展（已收敛）；低温微调+EMA（局部最优）；Turbo 迭代译码（无增益）；genie 均衡+解析 demap 不超神经 RX（RX 已在 genie 均衡天花板）。

## 3. 剩余上分点（三方共识排序）

1. **导频锚定解析 RX**（若我们的 v7 复现不足 +2.5，这是替代/叠加路径）——Qwen/Kimi 主力。
2. **低 SNR 段有损 JSCC**：低段 E 仅 50-57 是唯一大空间；Hamming(7,4) 有损量化（无误索引 87.5%）等，但必须整体优化"源失真+信道错误"（索引 BER=20% 时 Hamming(7,4) 66.3% < 同预算前缀 67.1%）。我们的 v6 微调版是这个方向的"学习码本"形态，嫁接到底座 ~65 上可能转正。
3. **便宜的可叠加项**（各 +0.1~0.5，链式热启动）：逐流学习功率分配（+0.3~0.5）、速率阶梯精确重复+LLR 合并+后验调档（+0.5~1）、导频残差通路（+0.11）、RE 级插值预编码（+0.09）。
4. **多接收机 LLR 集成**（+0.1~0.2）：冻结空口，差异化 RX 从头训，贪心权重。
5. p10 / CSIT / 干扰消除：已关闭。

## 4. 我们的结合执行队列（mac-mini）

- **[进行中] v7 = 副本物理接收机**（GLM-1 机制复现），40k 步 MPS，完成后严格配对评测 vs v3。
- **v8 = 导频锚定**（Qwen/Kimi 机制）：TX 在 12 固定 RE 发 rank-4 Hadamard 导频穿同一预编码（波形改动，可从 v7 热启动）；RX ridge-LS 估子带 H_eff + 子带恒定 RZF；保留 v7 的副本物理特征作为补充通路。目标 ~64-65。
- **v9 = 便宜叠加**（每次一项，双协议确认）：逐流功率 → 速率阶梯(重复+LLR合并+调档) → 导频残差通路 → 插值预编码。
- **v10 = 第二接收机集成**：冻结 v9 空口，差异化 RX 从头训，贪心 LLR 权重。
- 每步遵循：诊断先行、配对评测、<0.1 双协议复现、EMA。
