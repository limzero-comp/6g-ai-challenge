# 评分、物理链路与既有结论审计

审计范围：仓库中的官方 `modelEval.py`、`modelTrain.py`、`modelDesign.py`、中英文参赛指南，以及旧 `data_explore*.py`、`DATA.md`、`README.md`。本次未启动训练。指南通过只读提取 DOCX 内 `word/document.xml` 核对；以下以当前可执行评测接口为实现依据，不把旧报告中的模拟分数当作实测模型成绩。

## 1. 应固定下来的评测契约

- 每个 UE 输入 **1152 bit**，两用户合计 2304 bit。两份指南的参数表均明确写“多用户下行最大传输总比特数 Bmax = 2304”，但此前接口段又把单用户长度写成 `Bmax`，存在符号复用歧义。`modelEval.py:19,138` 明确采用每用户 `144*8=1152`。
- `Encoder(H_i, snr_i)` 输出 `[batch,96] complex64`；`Transmitter(bits_list, feedback_list, snr_dl)` 接收 SNR 形状 `[2,batch]`，输出 `X:[batch,16,144] complex64` 和一个公共 `ctrl:[batch,5]` 二进制张量。
- `Receiver(Y_i,H_i,ctrl,snr_i)` 必须输出 `[batch,B] float32`，`1 <= B <= 1152`，且全部有限；非负 LLR 判为 **1**。常用通信文献中的 LLR 定义未必使用这个符号约定。
- 接收机知道本用户真实信道、本用户下行 SNR、公共控制字；**不知道用户编号、另一用户 H/SNR、反馈噪声、基站实际收到的反馈，也不知道由这些量生成的预编码矩阵 W**。
- 上行先逐样本将 `mean(abs(U)**2)` 归一为 1，然后添加方差 `10**(-(snr_dl-10)/10)` 的复高斯噪声。
- 下行先逐样本将 `mean_sc(sum_tx(abs(X)**2))` 归一为 1，然后做 `Y=HX+n`；没有在 H 上额外除以 `sqrt(16)` 或标准化。每个复噪声的两个实部方差各为总方差的一半。
- 下行约束是 **144 个子载波全阵平均总功率为 1**，并非每个子载波功率都必须等于 1。因此允许频率间功率再分配；任何 pilots、数据、控制的带内辅助信息都应共同计入 X 的能量。
- 两用户 SNR 独立，在一次 144 SC block 内各自固定。公平分来自 **逐 UE、逐 block 的实际 bit 正确率分数**的第 10 百分位，并非逐子载波 SINR、条件期望 BER 或 SNR 的第 10 百分位。
- 官方本地脚本从训练数据抽 2000 次、每次 batch=1，期间可重复抽到同一样本；它不是独立泛化验证集。

## 2. 旧报告中会改变建模路线的错误

1. **QAM 硬判决缺少 `/2`。** 星座实轴位置为 `c*(2*i-m+1)`，逆映射应为 `(received.real/c+m-1)/2`。旧代码的 `received.real/c+(m-1)/2` 会在高 SNR 仍大量判错，故旧表中约 56 分的“未编码天花板”、自适应仅 +0.25 等结论失效。
2. **PCA 合并了两个 UE。** `G` 包含 `[sample,UE,RX,TX,16tap]`，加实虚后是 `2*2*16*16*2=2048` 实维；单用户应是 1024 实维，因此旧结果不是用每用户 192 实维反馈对单用户信道作出的误差标定。还应将截掉的 128 个 delay taps 的误差加回原始频域分母。训练样本上的 PCA 是一个线性压缩参考，不是一般非线性方案的“信息论下界”。
3. **角度 FFT 轴错误。** `Hp:[N,UE,RX,2pol,8pos,16tap]` 上 `axis=-3` 变换的是 2 个分组，而非 8 个阵位；旧角度熵与方向分布结论无效。
4. **SNR 和评分聚合粒度错误。** 旧模拟按 `N*144` 重抽 SNR，将每个 SC 当成独立样本统计 p10；正确模拟须先在一个 block 内固定各 UE SNR，再汇总 144 SC，最后取所有 UE-block 分数的 p10。
5. **SU/oracle 逻辑有误。** SU 应按预期得分而非仅最大奇异值增益选用户；旧未编码 oracle 比较时遗漏了未服务用户的 50 分基线；选 SU 后又把已服务得分固定记到 user2。即使修复，这种 perfect-CSI oracle 也不是当前接口可达模型。
6. **“p10≈52 的物理墙”和“永远 MU”缺乏依据。** 下文的率失真分析已足以否定前者；后者需在正确链路和统计口径下作消融，并处理实际低 SNR 上行反馈。
7. **结构推断应保留限度。** 两个 8 天线高相关块支持“两组空间结构”的模型先验，但不能单凭相关矩阵证明物理阵列就是双极化 ULA；零均值不能排除随机相位的 LOS；3% 级 delay 截断残差不能解释为 float16 的量化误差。有限频率窗和非整数 delay 会造成 IFFT 泄漏。
8. **信道强度平滑不等于预编码方向平滑。** 奇异值变化小仍可伴随奇异向量旋转。选择 48 SC 一个 W 前，应测量子带平均 H 的重建误差、主空间对齐和实际 beamforming 损失；逐 SC 与多粒度频域建模都应保留。

数据侧可复现修正结果应以本轮审计脚本输出为准，旧 F10/F11/F12 数值不再作为架构排除依据。

## 3. 这个赛题优化的是失真，不是块成功率

精确分数可以写成

`score = 50 + (100/1152) * sum_{j<=B}(1[pred_j=bit_j]-0.5)`。

因此目标是正确位数相对随机猜测的增益；没有 CRC、没有全块正确才得分的门槛。输出长度 B 的选择会影响效率，也会改变噪声导致的分数方差与 p10。输出全零 LLR 会全部判为 1，绝不是官方意义上的弃权；`B=0` 则被禁止。

若假设一个理想标量通道每 RE 有 C bit 容量，先可靠传输 `144*C` 个前缀 bit、其余按 0.5 处理，仅得到策略参考 `50+6.25*min(C,8)`。它**不是**任意 Hamming 失真方案的得分上界。

对于独立均匀 Bernoulli 源，渐近 Hamming 率失真函数为 `R(D)=1-Hb(D)`。在每源 bit 可用 `C/8` 个可靠信息 bit 的理想分离假设下，解 `1-Hb(D)=min(C/8,1)`，全长重建对应分数 `100*(1-D)`。例如 C=0.3 时，可靠前缀参考为 51.875 分，而渐近率失真参考约为 61.351 分。这个差距说明“容许所有位小概率出错”值得与“少数位近乎无误”并行研究；它不承诺 144 RE 有限块长、MU 干扰、噪声反馈下可达到此数值。[Polyanskiy–Wu 信息论教材，第 25–27 章](https://people.lids.mit.edu/yp/homepage/data/itbook-2022.pdf)；[Martinian–Wornell，二元量化与擦除量化](https://sia.mit.edu/wp-content/uploads/2015/04/2004-martinian-wornell-allerton.pdf)。

因而建议至少保留：逐 RE 可解释基线、可变前缀跨 RE 编码、全长跨 RE 有损联合编码这三条路线；使用同一个正确评估器比较，不能由旧 capacity-prefix 曲线提前宣布胜者。

## 4. 反馈瓶颈与接收端信息限制

96 个单位平均功率复 AWGN 符号在理想高斯输入下，信息容量参考为 `96*log2(1+10**((snr_dl-10)/10))` bit/feedback block。下行 SNR = -20/-10/0/10/20 dB 时，分别仅约 **0.138 / 1.378 / 13.20 / 96 / 332.1 bit**。公式来自复高斯 AWGN 容量；逐 block 球面归一化与有限块长不会让这个理想上界更乐观地可达。[Polyanskiy–Wu 信息论教材，Gaussian channels](https://people.lids.mit.edu/yp/homepage/data/itbook-2022.pdf)。

这比“96 复数等于 192 个无噪实数”重要得多。低 SNR 时，transmitter 几乎没有瞬时 CSI；decoder 应明确 SNR 条件化，学习/使用收缩到统计先验的行为，避免噪声驱动的大幅随机波束。CSIT 重建应按上行 SNR 分桶报告 NMSE，并结合最终数据链路得分决定有用特征，而非只追求全 H MSE。

公共 5 bit 一共 32 个控制状态，不能直接表示两个用户各自独立的 32 档速率。接收机没有 user ID，单纯“前两位属于 UE0、后三位属于 UE1”也不能让当前共享 Receiver 知道该读哪段。

可行的稳健设计包括：

- B 由双方已知的**本用户 SNR**经相同确定性函数给出，公共控制字只选择全局策略；或者用明确可辨识的带内机制完成资源/用户关联。
- 用户维度保持交换等变，避免固定 UE 索引嵌入、不同用户专属码本却不提供可解码关联信息。
- 如果 W 依赖 noisy feedback 和另一用户，不允许 receiver 通过真实 own H 假装得到准确 W；可用 pilots 估计 effective channel，再补足 own-stream association，或让神经接收机显式学习此不确定性。
- pilots 的位置、幅度、作用范围需与 W 的频域变化一致；不能在不同 W 的 SC 上用一个导频估计替代全部 SC。
- 全链路 forward 不通过 Python 全局变量、类实例间缓存、调用顺序等旁路把 TX 信息直接交给 RX。指南明确要求各模块部署在不同物理端、遵守规定的信息接口。

## 5. 可训练目标与验证建议

### 稳定训练代理

令 `m_j` 为是否发送前缀的 mask，`z_j=(2*b_j-1)*logit_j`。逐 UE-block 的软分数可取

`s = 50 + 100/1152 * sum_j m_j*(sigmoid(z_j/T)-0.5)`。

这是 hard correctness 的平滑代理，温度 T 与 logit 尺度会影响它，并不是校准后的真实 bit 正确概率。早期仍宜用 BCE 稳定训练，后期再混合软分数并严格按独立 hard-score 选 checkpoint。

变 B 时不能把 active bits 的 mean BCE 直接当比赛分数来比较。一个与“未传部分零增益”一致的训练代理是 `sum_j m_j*(BCE_j-log(2))/1152`；中心化只提供合理基线，仍须用真实评分校验其对速率策略的影响。

公平项可先试 lower-tail CVaR：

`CVaR_alpha(s) = max_tau {tau - mean(relu(tau-s))/alpha}`，`alpha=0.1`。

其梯度比 minibatch 单点分位数更稳定，优化底部 10% 的平均表现。**CVaR 不等于第 10 百分位**，通常更保守，所以不应机械认定 `0.7 mean + 0.3 CVaR` 与官方最优相同；应消融公平权重并使用官方硬分位数选模型。也可在 detached running p10 附近加权，而非把最坏的不可改善噪声样本无限增权。公式是将风险损失的 CVaR 变分表达式应用于负分数所得：[Rockafellar–Uryasev，Conditional value-at-risk for general loss distributions](https://www.sciencedirect.com/science/article/abs/pii/S0378426602002716)。

### 正确验证最小集

1. 固定互斥 train/validation/test 样本 ID；PCA/归一化统计只用 train。若存在重复或邻接相关样本，额外检查按样本组划分的稳健性。
2. 使用固定的 bits、两用户 block SNR、UL/DL noise 随机种子做各模型配对比较，至少覆盖多个独立 seed。不同权重/不同速率同时用同一批随机实现，减少比较噪声。
3. 汇总逐 UE-block 的 hard score，报 mean、p10、0.7/0.3 final、按 own SNR/对方 SNR/信道增益分桶结果。以 block 为单位配对 bootstrap，避免把同一 block 的两个相关 UE 当完全独立样本。
4. 可变 B 的官方评测使用 batch=1；训练可固定 1152 张量配 mask。不能把 padded 0 LLR 当 0.5 得分，也不能在一个 dense batch 中伪装不同样本各自的输出长度。
5. 验证 UE 交换等变性、batch=1 与可支持 batch 的一致性、正能量与有限值、CPU/GPU device、保存后无参构造加载、单文件提交依赖。改变 SNR/反馈随机种子时不得依赖调用顺序或跨模块缓存。
6. 用已知 QPSK 在高 SNR 接近零 BER、零信息期望 50、长度 B 的全对结果 `50+50*B/1152` 检查评估器。物理链路比较同时列 no-CSIT、noiseless-feedback 和真实 noisy-feedback 三种条件，明确 oracle 只供诊断。
7. 除正式训练外，仅做小张量前向/反向、形状/保存加载检查即可验证当前交付代码；没有训练就不应宣称某版本性能已领先。

有限块长与抽样噪声也意味着“未服务 UE 恰好 50”只在允许完全弃权或计算条件期望时成立。本地接口要求至少输出 1 bit，此时无信息用户实际分数是 `50±50/1152`；全长猜测又有更大方差。应在真实输出契约中测量这些策略，而不是从期望值直接推断 p10。
